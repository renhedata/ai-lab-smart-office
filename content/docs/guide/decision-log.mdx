---
title: 决策记录
description: 以 ADR 形式保存影响范围、原因和复盘结论。
---

每个会影响成本、体验、安全、施工或后续维护的选择，都应新增一份决策记录。文件名采用 `YYYY-MM-DD-主题.md`，例如 `2026-07-31-iot-vlan-isolation.md`。

## 模板

```md
# ADR-001：决策名称

- 日期：YYYY-MM-DD
- 状态：提议 / 已批准 / 已替代
- 关联 Issue：#编号

## 背景

当前问题、约束与目标。

## 备选方案

1. 方案 A：优点 / 缺点 / 成本
2. 方案 B：优点 / 缺点 / 成本

## 决定

最终选择及原因。

## 影响与回滚

对预算、施工、运维的影响；若失败如何恢复。
```

<Callout>

决策记录不追求长篇大论，关键是让半年后接手项目的人明白：当时为什么这样做、影响什么、由谁确认。

</Callout>
