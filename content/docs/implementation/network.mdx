## 开工前清单

- [ ] 完成现场勘查，标注机柜、弱电箱、电源和已有线路。
- [ ] 确认运营商线路、静态 IP、主备链路与设备责任边界。
- [ ] 建立网段、VLAN、SSID、设备命名和地址分配表。
- [ ] 审核 PoE 功耗、交换机端口数量、AP 覆盖和 UPS 续航。
- [ ] 明确有线、无线和 IoT 的安全隔离策略。

## 智能化网络扩展提案

[智能化总体方案](/docs/implementation/smart-office-plan/)建议将 Home Assistant、MQTT 和协议网关放入独立的“自动化服务区”，与 IoT 设备区、办公区和管理区分开。该分区目前属于设计提案，不代表已经实施；精确 VLAN、地址、DHCP、防火墙和回退方案须完成内部评审后再变更现场网络。

### Matter/Thread 试验边界

Matter 依赖本地 IPv6、mDNS 和组播发现，在 VLAN、组播过滤和 IGMP snooping 环境中可能遇到兼容性问题。第一阶段使用单独测试网，让测试设备、Thread 边界路由器和 Matter 控制器位于相同 VLAN，完成配网、断网控制、重启、OTA 和恢复测试后再评估是否纳入正式网络。Zigbee 和 Thread 使用独立无线适配器，不让同一支无线电在生产环境同时承载两种协议。

参考 [Home Assistant Matter 集成的网络要求](https://www.home-assistant.io/integrations/matter/) 和 [Connect ZBT-2 对单协议无线电的说明](https://www.home-assistant.io/connect/zbt-2/)。

## 验收证据

对每一项网络改造，保存端口标签照片、布线测试结果、配置备份版本、覆盖测试和内部变更记录。
