# 自动化场景

## 场景模板

| 字段 | 内容 |
| --- | --- |
| 场景名称 | 如：会议室自动进入会议模式 |
| 触发条件 | 人体存在、预约开始、墙面开关、时间段 |
| 执行动作 | 灯光、窗帘、空调、屏幕、通知 |
| 安全边界 | 允许自动关，禁止自动开；手动优先 |
| 回退机制 | 平台/网络故障时，实体开关仍可用 |
| 测试证据 | 测试日期、环境、结果、关联 Issue |

## 最小可行场景

1. **下班节能**：无人状态下关闭非必要照明和显示设备。
2. **会议模式**：预约或手动触发后调整照明、屏幕和空调。
3. **环境提醒**：CO₂、温湿度或漏水达到阈值时推送告警。

::: warning 先测试再上线
自动化第一次启用时应设定观察期，避免因误触发影响办公。涉及门禁、消防和人身安全的系统不得由普通自动化规则直接控制。
:::
