## 提建议与贡献

### 评论某一页

页面末尾的“讨论本文”适合补充事实、指出错误或追问具体内容。登录 GitHub 后即可评论；留言会归到当前页面，方便后续追溯。

### 提出建议

先阅读[参与共创](/docs/participation/)，用“场景—发生什么—频率—影响—期望”描述问题。不必知道设备或协议；项目组有责任把问题核实、比较简单做法与技术做法，并回应结果。

### 提交贡献

1. 在[项目仓库](https://github.com/renhedata/ai-lab-smart-office)中 Fork 或创建分支，并先查看相关页面和已有 Issue。
2. 每个贡献只解决一个明确问题；更新方案、图纸、设备台账或验收记录时，附上可公开的依据和关联 Issue。
3. 本地运行 `npm run dev` 预览，并执行 `npm run build` 确认静态站点能构建。
4. 提交 Pull Request，写清改动原因、影响范围和验证结果；涉及预算、施工、网络或长期维护的重要选择，在关联 Issue 中写清依据、影响和最终选择，并更新对应方案页面。

不要提交密码、密钥、门禁凭证、个人信息或未经脱敏的现场资料。
