## 采购前确认

- 是否满足现有协议、网络、安全与供电条件？
- 是否有本地控制、离线可用或开放接口？
- 是否支持稳定固件更新、备份和恢复？
- 是否已将耗材、安装辅料、售后和替换成本计入预算？

## 设备台账字段

| 字段 | 示例 |
| --- | --- |
| 资产编号 | `IOT-MEET-001` |
| 设备与型号 | 会议室人体传感器 / 型号待定 |
| 区域与用途 | 会议室 / 触发会议模式 |
| 网络标识 | MAC、IP、VLAN、接入端口 |
| 购置与保修 | 供应商、订单、购置日、保修截止日 |
| 配置位置 | 仓库路径、备份版本、关联文档 |
| 状态 | 计划中、在库、已安装、维修、报废 |

建议将每项采购作为 GitHub Issue，在其正文维护报价对比、最终选择、到货与验收结果；台账只记录已确定或已入库的信息。
