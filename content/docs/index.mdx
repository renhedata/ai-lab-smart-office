这个文档库用来连接方案、任务和现场证据。只是查看项目时，按“总览 → 专题 → 验收”阅读；需要推进工作时，按“查现状 → 建 Issue → 更新文档”操作。

## 只查看项目

1. 先看[项目总览](/docs/guide/project-overview/)，了解目标、范围和建议阶段。
2. 再看[办公室布局](/docs/guide/office-layout/)，确认房间名称、功能分区和图纸边界。
3. 根据关心的专题进入[当前网络现状](/docs/guide/architecture/)、[智能化总体方案](/docs/implementation/smart-office-plan/)或[自动化场景](/docs/implementation/automation/)。
4. 需要核对采购和交付时，查看[采购与设备台账](/docs/management/procurement/)和[施工与验收](/docs/management/acceptance/)。

## 维护或推进项目

1. 先阅读[协作与变更流程](/docs/guide/workflow/)，确认这项工作应进入文档、Issue 还是决策记录。
2. 搜索已有页面和 Issue，避免建立两份相互冲突的记录。
3. 新增费用、变更设备型号或布线、修改自动化规则、发现现场问题时，先建 Issue。
4. 结论稳定后修改对应的 MDX 文档；有重要取舍时，按[决策记录规范](/docs/guide/decision-log/)在[决策档案](/docs/decisions/)中新建或更新 ADR。

## 导航和搜索

### 顶部工具栏

“文档”是当前唯一的内容区。无论通过左侧目录打开哪一页，顶部都会保持在“文档”中。工具栏同时提供全文搜索、显示模式和 GitHub 入口。

### 左侧目录

左侧目录按“规划与协作、决策档案、方案与实施、交付与运维”分组。每个分组可以展开或收起；桌面端还可以用顶部的侧栏按钮收起整个目录。

### 本页目录

较长页面会显示“本页目录”，桌面端通常位于右侧。点击二级或三级标题，可直接跳到当前页的对应部分。

### 搜索

- 点击页面顶部的“搜索”，或按 `⌘ K`（macOS）/ `Ctrl K`（Windows、Linux）。
- 输入房间名称、设备类型、协议、场景或任务，例如“D会议室”、“窗帘”、“VLAN”或“验收”。
- 用方向键切换结果，按 Enter 打开，按 Esc 关闭。

## 内容存放位置

| 信息类型 | 存放位置 | 示例 |
| --- | --- | --- |
| 范围、空间、现状和协作规则 | `content/docs/guide/` | 项目总览、办公室布局、当前网络现状、协作流程 |
| 重要取舍的 ADR 决策记录 | `content/docs/decisions/` | 网络隔离、供电方式、设备协议或控制策略的选择 |
| 技术方案、实施要求和自动化规则 | `content/docs/implementation/` | 网络与弱电规划、智能化总体方案、自动化场景 |
| 采购、设备台账、施工与验收 | `content/docs/management/` | 报价选择、资产信息、验收结论 |
| 网页需要展示或下载的图纸与图表 | `public/` | SVG、PNG、PDF 和 CAD 下载包 |
| 待决、待做、现场问题或待验收事项 | GitHub Issue | 采购设备、修复 AP 覆盖盲区、场景测试不通过 |
| 对文档、图纸或配置的可审核变更 | Pull Request | 更新 VLAN 方案、修正点位或补充验收证据 |

密码、私钥、令牌、门禁凭证和个人敏感信息不得提交到文档、Issue 或 Pull Request。

</Callout>

## 推进一项工作

### 1. 查：确认现状和边界

先搜索相关房间、设备或系统，阅读现有方案、警告和待确认项。如果文档与现场不一致，先记录差异，不直接把假设当成结论。

### 2. 做：明确责任和验收方式

用 Issue 记录范围、区域或设备编号、负责人、预算或影响、成功标准和相关证据。涉及重要取舍时，在 `content/docs/decisions/` 建立 ADR，并在 Issue 与 ADR 中互相链接。

### 3. 记：让文档与现场重新一致

完成实施或评审后，更新对应方案、图纸、设备台账和验收记录，关联 Issue 与测试证据。每页标题下方的 GitHub 入口可直接打开源 MDX 文件。

<Callout title="最简单的判断">

查结论，看文档；推任务，建 Issue；改结论，提 Pull Request；做了重要取舍，在 `decisions/` 补 ADR。

</Callout>
